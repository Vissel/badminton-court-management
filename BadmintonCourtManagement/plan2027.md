## Definition of Done — Feature #1 (Import/Export Goods)

### Backend
- Bulk intake via `StockIntake` sheet (`Tên | Số lượng | Giá nhập | Đơn vị`) reuses preview/commit flow — preview returns `importToken` + per-row actions, commit applies the plan transactionally.
- `GET /api/inventory/export` produces xlsx with stock, avg cost, retail price, margin.
- All endpoints under `/api/inventory/**` return `403` for non-`rootuser` (same pattern as `ProductsController`).
- All mutations transactional — no partial stock state (project convention).

### Frontend
- Bulk Excel upload (preview → commit UX) on the inventory page.
- Export button downloads the inventory xlsx report.

### Verification
- Import preview/commit covered by service-level tests (adds, updates, reactivates, skips, errors).
- Export xlsx verified against on-hand stock from `SUM(stock_movement.quantity_delta)`.
