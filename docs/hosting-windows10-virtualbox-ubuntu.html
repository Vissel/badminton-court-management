Architecture overview

Everything the venue needs runs inside one Linux VM on the laptop. The laptop never needs a public IP, router port-forwarding or open inbound ports — the tunnel is dialled out from the VM.

Internet user
   |  https://quancaulong.example.com/caulong-tc-qa/
   v
Cloudflare edge  ----(outbound tunnel, cloudflared)----+
                                                       |
Windows 10 laptop  ====================================|
  |                                                    v
  +-- VirtualBox VM "badcourt-ubuntu"  (Ubuntu Server)
          |-- cloudflared  -> localhost:8080
          |-- Tomcat 11 / Java 21
          |     |-- caulong-tc-qa.zip            -> /caulong-tc-qa/   (React SPA)
          |     |-- bad-court-management-qa.war  -> /bad-court-management-qa/api/v1/...
          |-- MySQL 8   localhost:3306  (badminton-qa)
          |
          NIC1 = BRIDGED   -> real LAN (192.168.1.200) + internet
          NIC2 = HOST-ONLY -> 192.168.56.100, SSH/SCP admin from Windows

Two adapters, on purpose: the bridged NIC gives the VM a normal LAN identity (other phones/PCs can reach it directly, and it has internet for apt and the tunnel). The host-only NIC gives you an admin address that never changes, even when you move between Wi-Fi networks or the router hands out a new DHCP lease.

Part 0 — Before you install (Windows side checks)

0.1 Virtualization must be enabled in BIOS/UEFI

Task Manager (Ctrl+Shift+Esc) → Performance → CPU → bottom right: Virtualization: Enabled.

If Disabled: reboot → BIOS key (Dell F2, Lenovo F2/Enter, HP F10, Asus Del) → enable Intel Virtualization Technology (VT-x) / AMD-V and VT-d → save & reboot.

0.2 Hyper-V coexistence

VirtualBox 7.1 works while Hyper-V is active, but bridged networking and disk performance are smoother without it. Win+R → optionalfeatures.exe → uncheck:

  • Hyper-V (and all sub-items)
  • Virtual Machine Platform
  • Windows Hypervisor Platform
  • Windows Sandbox
  • Windows Subsystem for Linux

Then reboot. Also turn off the features that force the hypervisor on: Windows Security → Device security → Core isolation details → Memory integrity = Off, and Security processor → Credential Guard = Not enabled.

0.3 Note your laptop's active NIC name

PowerShell 
Get-NetAdapter | Select-Object Name, Status, MacAddress | Format-Table -AutoSize

You will need the exact Name of the adapter that currently has internet — typically Wi-Fi, Realtek PCIe GbE Family Controller, Intel(R) Wi-Fi 6 AX201.

0.4 Reserve a free LAN address for the VM's static IP

PowerShell 
ipconfig                              # note IPv4 + default gateway, e.g. 192.168.1.35 / 192.168.1.1
Test-Connection 192.168.1.200 -Count 1   # must NOT reply; pick another last octet if it does

Part 1 — Install VirtualBox

1.1 Download

  • Application: https://www.virtualbox.org/wiki/Downloads → VirtualBox 7.1.x — Windows hosts (.exe, ~120 MB).
  • Oracle VM VirtualBox Extension Pack 7.1.x (same page, .vbox-extpack; PUEL licence — personal/educational use). Needed for USB 2.0/3.0, RDP, disk encryption.

1.2 Run the installer

Defaults are fine. Watch for the “VirtualBox network interfaces — are you sure you want to install…” dialog and click Install: without it there is no Host-Only adapter and step 2.2 fails. Windows may show a driver-installation prompt — allow it. Your network connection drops for a few seconds; this is normal.

1.3 Add the Extension Pack

GUI → File → Preferences → Extensions → + → select the .vbox-extpack → Agree. Verify:

PowerShell 
cd "C:\Program Files\Oracle\VirtualBox"
.\VBoxManage.exe list extpacks

Expected line: Extension Pack #0: Oracle VM VirtualBox Extension Pack … Version: "7.1.x".

1.4 Download the Ubuntu ISO (no USB stick needed)

The VM boots the ISO directly. Save it to e.g. D:\vm-iso\:

  • Ubuntu Server 24.04.x LTS, amd64 — best-matched documentation: https://releases.ubuntu.com/24.04/ → ubuntu-24.04.x-live-server-amd64.iso (~3 GB).
  • Ubuntu Server 26.04.1 LTS (ubuntu.com/download/server) is equally fine — every command in this document is identical on both.
  • Pick Server, not Desktop: no GUI needed, less RAM, services run headless.

Part 2 — Create the VM

The command line is used so the adapter order is exact and reproducible. Run from C:\Program Files\Oracle\VirtualBox in PowerShell.

2.1 Base VM, CPU/RAM, disk, ISO

PowerShell 
$VBM = ".\VBoxManage.exe"
$VM  = "badcourt-ubuntu"
$ISO = "D:\vm-iso\ubuntu-24.04.3-live-server-amd64.iso"

& $VBM createvm --name $VM --ostype Ubuntu_64 --register --basefolder "D:\VirtualMachines"
& $VBM modifyvm   $VM --memory 6144 --vcpus 2 --cpus-exec on `
                    --nic1 intelpro1000 --nic2 intelpro1000 `
                    --boot1 dvd --boot2 disk --graphicscontroller vmsvga --vram 16

& $VBM storagectl --name $VM --controller "SATA" --add sata --controller IntelAhci --bootbus 1
& $VBM createhd   --filename "D:\VirtualMachines\$VM\$VM-disk001.vdi" `
                  --size 61440 --format VDI --variant Fixed
& $VBM storageattach --name $VM --controller "SATA" --type hdd `
                     --medium "D:\VirtualMachines\$VM\$VM-disk001.vdi"

& $VBM storagectl  --name $VM --controller "IDE" --add ide
& $VBM storageattach --name $VM --controller "IDE" --type dvddrive --medium $ISO

Sizing rationale

2 vCPU / 6 GB covers Tomcat (-Xmx1024m) + MySQL + cloudflared with the laptop still usable. --cpus-exec on is required for 64-bit guests on some hosts. Fixed VDI is slower to create but does not grow unpredictably and is measurably faster than dynamically expanding. Intel PRO/1000 (--nic… intelpro1000) is the best-supported Linux driver under VirtualBox.

2.2 Network — the important part

PowerShell 
# Adapter 1: BRIDGED to the laptop's real NIC
#   -> VM joins the physical LAN, gets internet, is visible to phones/PCs on the Wi-Fi
& $VBM modifyvm $VM --bridgeadapter1 "Wi-Fi"     # <-- exact Name from step 0.3

# Adapter 2: HOST-ONLY
#   -> stable private Windows <-> VM channel for SSH/SCP, unaffected by Wi-Fi changes / AP isolation
& $VBM list hostonlyifs
& $VBM modifyvm $VM --hostonlyadapter2 "VirtualBox Host-Only Ethernet Adapter"

Pin the MAC addresses so DHCP reservations and your netplan match what you wrote on paper:

PowerShell 
& $VBM modifyvm $VM --macaddress1 080027A1B2C3
& $VBM modifyvm $VM --macaddress2 080027A1B2C4
& $VBM showvminfo $VM | Select-String "NIC"

GUI equivalent (if you prefer clicking)

Settings → Network: Adapter 1 Attached to: Bridged Adapter, Name = your Wi-Fi/LAN NIC; Adapter 2 Attached to: Host-only Adapter, Name = VirtualBox Host-Only Ethernet Adapter. Advanced → Type: Intel PRO/1000 MT (PRO/1000). If the Host-only list is empty, open File → Tools → Network Manager → Host-only and click Create.

2.3 Start it for the installation

PowerShell 
& $VBM startvm $VM            # GUI window - you need to watch the installer
# & $VBM startvm $VM --type headless   # later, for everyday operation

Part 4 — Network configuration inside Ubuntu

4.1 Identify interfaces

Ubuntu (VM console) 
ip -br link
ip -4 addr
# example output
#   lo        UNKNOWN
#   enp0s3    UP  192.168.1.57/24      <- BRIDGED (DHCP from your router)
#   enp0s8    UP  192.168.56.101/24    <- HOST-ONLY
ip route | grep default                # must be via enp0s3

Cross-check the MACs with what you pinned in 2.2: the interface whose MAC ends B2:C3 is the bridge, B2:C4 is host-only. If the names differ (e.g. ens33), use your real names in the netplan file.

4.2 Confirm the host-only gateway on Windows

VirtualBox GUI → File → Tools → Network Manager → Host-only tab → VirtualBox Host-Only Ethernet Adapter → IPv4 Address = 192.168.56.1, mask 255.255.255.0. On the DHCP-Server tab, uncheck “Enable Server” (or at least keep its pool away from 192.168.56.100), then close the dialog.

PowerShell 
Get-NetIPAddress -AddressFamily IPv4 | Where-Object InterfaceAlias -like "*Host-Only*" |
    Select-Object InterfaceAlias, IPAddress, PrefixLength

4.3 Write a single netplan file

Ubuntu Server ships cloud-init netplan files that are re-applied on boot; keeping exactly one /etc/netplan/*.yaml removes the usual “duplicate config wins” failures. YAML: spaces only, never tabs.

Ubuntu 
sudo rm -f /etc/netplan/*.yaml
sudo nano /etc/netplan/50-cloud-init.yaml
/etc/netplan/50-cloud-init.yaml — stage 1 (DHCP on the bridge) 
network:
  version: 2
  ethernets:
    enp0s3:                     # NIC 1 - BRIDGED: joins the real LAN
      dhcp4: true
    enp0s8:                     # NIC 2 - HOST-ONLY: static, admin path from Windows
      dhcp4: false
      addresses:
        - 192.168.56.100/24
      routes:
        - to: default
          via: 192.168.56.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
Ubuntu 
sudo chmod 600 /etc/netplan/50-cloud-init.yaml
sudo netplan try        # auto-reverts after 120s if you lock yourself out - safest first apply
# or, once confident:
sudo netplan apply

Why the host-only default route is harmless

Linux keeps one main routing table; the DHCP lease on enp0s3 installs default via 192.168.1.1 with a lower metric than netplan’s static one, so internet traffic still leaves via the bridge — verify with ip route get 1.1.1.1 after applying. If it ever picks enp0s8, delete the static default route from the enp0s8 block: Windows→VM SSH still works, because it is the same L2 segment. The route is there only so the VM can resolve names if the bridge is momentarily down.

4.4 Verify stage 1

Ubuntu 
ip -4 addr show enp0s3 | grep inet
ip -4 addr show enp0s8 | grep inet       # 192.168.56.100
ping -c2 192.168.56.1                    # Windows over host-only
ping -c2 8.8.8.8                         # internet over bridge
ping -c2 ubuntu.com                      # DNS works
ip route get 1.1.1.1                     # dev enp0s3  <-- required

4.5 Make the bridged address static (server-grade)

So LAN bookmarks, the tunnel origin and router rules never break. Substitute your own subnet/gateway from 0.3–0.4:

/etc/netplan/50-cloud-init.yaml — final 
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      dhcp6: false
      addresses:
        - 192.168.1.200/24
      routes:
        - to: default
          via: 192.168.1.1
        - to: 192.168.1.0/24
          via: 192.168.1.1
          scope: link
      nameservers:
        addresses: [192.168.1.1, 1.1.1.1, 8.8.8.8]
    enp0s8:
      dhcp4: false
      addresses:
        - 192.168.56.100/24
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
Ubuntu 
sudo netplan apply
ip -4 addr show enp0s3 | grep inet       # 192.168.1.200/24
ping -c2 192.168.1.1                     # router
ping -c2 8.8.8.8                         # internet
PowerShell 
ping 192.168.56.100 -n 2
ping 192.168.1.200  -n 2      # both must reply

Optionally reserve 192.168.1.200 → 08:00:27:A1:B2:C3 as a static DHCP lease on the router too — it prevents a duplicate-IP if you ever flip back to DHCP. Otherwise keep the pure-static config above.

Fully unattended alternative

Re-run the install with an autoinstall (Subiquity autoinstall endpoint) supplying the netplan above plus a late-commands block that installs OpenSSH and creates your user — the user-data is a small cloud-init YAML. Ask for that file if you want to rebuild this VM repeatably.

ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub | `

Shared folder (optional convenience)

PowerShell

Part 6 — Java 21, Tomcat 11, WAR deployment

Ubuntu (over SSH) 
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y openjdk-21-jdk-headless curl unzip
java -version                       # openjdk 21.x

sudo mkdir -p /home/admin/deploy
cp ~/deploy_tmp/*.war ~/deploy_tmp/*.zip /home/admin/deploy/ 2>/dev/null; ls -l /home/admin/deploy

# dedicated service user + Tomcat 11 (matches apache-tomcat-11.0.18)
sudo useradd -r -m -s /usr/sbin/nologin tomcat
cd /opt
sudo curl -LO https://dlcdn.apache.org/tomcat/tomcat-11/v11.0.18/bin/apache-tomcat-11.0.18.tar.gz
sudo tar xzf apache-tomcat-11.0.18.tar.gz && sudo mv apache-tomcat-11.0.18 tomcat
sudo rm -rf /opt/tomcat/webapps/*
sudo cp /home/admin/deploy/bad-court-management-qa.war /opt/tomcat/webapps/
sudo cp /home/admin/deploy/caulong-tc-qa.zip           /opt/tomcat/webapps/caulong-tc-qa.zip
sudo chown -R tomcat:tomcat /opt/tomcat
ls -l /opt/tomcat/webapps

File name = context path

  • caulong-tc-qa.zip → deployed URL /caulong-tc-qa/, matching the QA React build’s homepage value.
  • Deploying the PROD build instead? Name it caulong-tc.zip so the URL is /caulong-tc/ and the bundled asset paths resolve.
  • bad-court-management-qa.war → API root /bad-court-management-qa/api/v1/….
  • Want the SPA at /? Rename to ROOT.zip and build React with homepage: "/" — otherwise keep the subpath exactly as the build expects.

systemd unit for Tomcat

/etc/systemd/system/tomcat.service 
[Unit]
Description=Apache Tomcat 11 - Badminton Court Management
After=network-online.target mysql.service
Wants=network-online.target

[Service]
Type=forking
User=tomcat
Group=tomcat
Environment=JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
Environment=CATALINA_HOME=/opt/tomcat
Environment=CATALINA_BASE=/opt/tomcat
Environment=CATALINA_PID=/opt/tomcat/temp/tomcat.pid
Environment="CATALINA_OPTS=-Dliquibase.secureParsing=false -Xms512m -Xmx1024m -Dfile.encoding=UTF-8"
ExecStart=/opt/tomcat/bin/startup.sh
ExecStop=/opt/tomcat/bin/shutdown.sh
Restart=on-failure
RestartSec=10
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target

-Dliquibase.secureParsing=false is required by the Liquibase changelog setup — it is the same flag your Windows catalina.bat workaround adds. The unit above is therefore the only place JVM options need to be set.

Ubuntu 
sudo systemctl daemon-reload
sudo systemctl enable --now tomcat
sleep 15
curl -I http://localhost:8080/caulong-tc-qa/         # expect HTTP/1.1 200 OK
sudo journalctl -u tomcat -n 60 --no-pager
ls /opt/tomcat/logs/ && sudo tail -50 /opt/tomcat/logs/catalina.out

If you get a bare “Apache Tomcat 404” page instead of a Spring error body, that is a wrong context path, not a dead application — list /opt/tomcat/webapps and match the names exactly.

Part 7 — MySQL inside the VM

Ubuntu 
sudo apt install -y mysql-server
sudo mysql <<'SQL'
CREATE DATABASE IF NOT EXISTS badminton-qa;
CREATE USER IF NOT EXISTS 'badmintonqa-user01'@'localhost'
  IDENTIFIED WITH mysql_native_password BY 'user01password';
GRANT ALL PRIVILEGES ON `badminton-qa`.* TO 'badmintonqa-user01'@'localhost';
FLUSH PRIVILEGES;
SQL

# optional: load an existing QA dump instead of letting Liquibase build from scratch
sudo mysql -u root < /home/admin/deploy/badminton-qa.sql

sudo systemctl status mysql --no-pager | head -5

Point the app at it in the QA properties:

application-qa.properties (datasource lines) 
spring.datasource.url=jdbc:mysql://localhost:3306/badminton-qa?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Ho_Chi_Minh
spring.datasource.username=badmintonqa-user01
spring.datasource.password=user01password

Legacy database adoption: the WAR self-adopts an existing database with zero manual steps — changesets 001–028 are frozen and accept any stored checksum, 025 auto-skips on databases migrated under the old rbac-jwt.sql lineage, and only the additive 029–031 apply on first boot. Old data is 0-impact, so restoring a mysqldump is optional; Liquibase creates the schema when starting empty. Still take a backup/snapshot before the first boot against real data.

Keep MySQL bound to localhost (the default). If you must use the Windows MySQL instead: spring.datasource.url=jdbc:mysql://192.168.56.1:3306/…, create the user with host '%', set bind-address=0.0.0.0 in the Windows my.ini, and open 3306 in the Windows firewall for the host-only subnet only.

Part 8 — Cloudflare Tunnel to your domain

No public IP, no router login, no port-forward, no ISP call — and it works behind the CGNAT and inbound-80/443 blocks typical of residential ISPs. Free HTTPS included.

8.1 Prepare the domain

  • Buy a domain, add a site at dash.cloudflare.com, and set your registrar’s nameservers to the two Cloudflare gives you.
  • Wait until the zone status is Active (nslookup -type=ns yourdomain.com 1.1.1.1 should show Cloudflare NS). Free plan is enough; the tunnel creates its own DNS record.

8.2 Authenticate from Windows (the VM has no browser)

PowerShell 
$cf = "$env:TEMP\cloudflared.exe"
Invoke-WebRequest "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile $cf
& $cf tunnel login                     # browser opens -> choose your zone
& $cf tunnel list                       # sanity check: API reachable

scp "$env:USERPROFILE\.cloudflared\cert.pem" admin@192.168.56.100:/home/admin/cert.pem

8.3 Create the tunnel inside Ubuntu

Ubuntu (as your user, not root) 
sudo curl -L "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64" `
     -o /usr/local/bin/cloudflared
sudo chmod +x /usr/local/bin/cloudflared
cloudflared --version

mkdir -p ~/.cloudflared
mv ~/cert.pem ~/.cloudflared/cert.pem

cloudflared tunnel create bad-court
#  -> "Tunnel credentials written to /home/admin/.cloudflared/<UUID>.json"
UUID=$(basename "$HOME/.cloudflared" 2>/dev/null; ls ~/.cloudflared/*.json | head -1 | xargs basename | cut -d. -f1)
echo "Tunnel UUID: $UUID"

cloudflared tunnel route dns bad-court quancaulong.example.com
# extra hostnames you may want:
# cloudflared tunnel route dns bad-court api.quancaulong.example.com
~/.cloudflared/config.yml 
tunnel: <TUNNEL-UUID>
credentials-file: /home/admin/.cloudflared/<TUNNEL-UUID>.json

ingress:
  - hostname: quancaulong.example.com
    service: http://localhost:8080
  # - hostname: api.quancaulong.example.com
  #   service: http://localhost:8080/bad-court-management-qa
  - service: http_status:404

Order matters: the first matching hostname wins and the bare service: line must stay last. Replace <TUNNEL-UUID> in both places with the value printed by tunnel create.

8.4 Install as a service

Ubuntu 
sudo cloudflared service install
# writes /etc/systemd/system/cloudflared.service (runs as root, reads /root/.cloudflared)

sudo mkdir -p /etc/cloudflared
sudo cp ~/.cloudflared/config.yml /etc/cloudflared/
sudo cp ~/.cloudflared/*.json     /etc/cloudflared/
sudo cp ~/.cloudflared/cert.pem   /etc/cloudflared/
sudo sed -i "s#/home/admin/.cloudflared/#/etc/cloudflared/#g" /etc/cloudflared/config.yml
sudo chown -R root:root /etc/cloudflared && sudo chmod 600 /etc/cloudflared/*.json

sudo systemctl daemon-reload
sudo systemctl enable --now cloudflared
sudo systemctl status cloudflared --no-pager | head -12
sudo journalctl -u cloudflared -n 30 --no-pager | grep -Ei "registered|connection|established"

Healthy log: "Registered tunnel connection" ×4. Then test from anywhere: https://quancaulong.example.com/caulong-tc-qa/.

LAN-only variant (skip Cloudflare entirely)

Browse to http://192.168.1.200:8080/caulong-tc-qa/ from any device on the venue Wi-Fi. To use a name anyway, add a DNS A record quancaulong.local → 192.168.1.200 on your router (if it serves DNS), or edit each client’s hosts file — C:\Windows\System32\drivers\etc\hosts: 192.168.1.200 quancaulong.local.

If you do have a real public IP

Check: curl -s ifconfig.me in the VM vs the WAN IP shown in the router. Identical → public. If it starts with 10.x, 100.64–127.x or 172.16–31.x → CGNAT, use the tunnel. With a real public IP you may instead forward 80/443 on the router to 192.168.1.200 and let Caddy terminate TLS: sudo apt install caddy + caddy reverse-proxy --from quancaulong.example.com --to localhost:8080, plus ddclient if the IP is dynamic. Only 80/443 get exposed either way.

Part 9 — Firewall, keep-alive, boot resilience

9.1 Ubuntu side

Ubuntu 
sudo apt install -y ufw
sudo ufw allow from 192.168.56.0/24 to any port 22 proto tcp
sudo ufw allow from 192.168.1.0/24  to any port 22 proto tcp
sudo ufw default deny incoming
sudo ufw enable
sudo ufw status verbose

# what is reachable from the LAN? 8080/3306 should NOT appear
sudo ss -tlnp | grep -E ':(22|8080|3306)'

To force Tomcat localhost-only, edit /opt/tomcat/conf/server.xml:

/opt/tomcat/conf/server.xml (Connector) 
<Connector port="8080" protocol="HTTP/1.1" address="127.0.0.1"
           connectionTimeout="20000" redirectPort="8443" />

That is the tightest setup — the tunnel is then the only way in. Drop the address attribute if you also want direct LAN access on :8080, and in that case scope it: sudo ufw allow from 192.168.1.0/24 to any port 8080.

Ubuntu 
sudo systemctl disable --now sleep.target suspend.target hibernate.target hybrid-sleep.target
sudo apt install -y unattended-upgrades

9.2 Windows laptop side — the VM is only as alive as its host

PowerShell (admin) 
powercfg /change standby-timeout-ac 0
powercfg /change disk-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /h off                       # hibernation off: suspend would kill the VM

Lid close → do nothing: Control Panel → Hardware and Sound → Power Options → Choose what closing the lid does → “Close the lid” on Plugged in = Do nothing.

Autostart the VM at boot, headless:

PowerShell (admin) 
schtasks /Create /TN "StartBadcourtVM" /SC ONSTART /RU SYSTEM /F `
  /TR "'C:\Program Files\Oracle\VirtualBox\VBoxManage.exe' startvm badcourt-ubuntu --type headless"

schtasks /Run   /TN "StartBadcourtVM"        # test immediately
schtasks /Query /TN "StartBadcourtVM" /V /FO LIST | Select-String "Last|Next|Status"

Inside Ubuntu the services come up on their own — verify: systemctl is-enabled tomcat mysql cloudflared → three enabled.

9.3 Snapshots — your undo button

PowerShell 
& $VBM snapshot take  badcourt-ubuntu "pre-tunnel"
& $VBM snapshot list  badcourt-ubuntu
& $VBM snapshot delete-child badcourt-ubuntu "pre-tunnel"    # once all is good
& $VBM closevm badcourt-ubuntu             # ACPI shutdown, like a real server power-off

Off-laptop backup: VBoxManage export badcourt-ubuntu -o D:\backup\badcourt-ubuntu.ova, plus a nightly mysqldump cron inside Ubuntu — the database is the real asset, not the VM.

Symptom Likely cause Fix

Bridged NIC shows “network cable unplugged” in the installer wrong --bridgeadapter1 name, or a VPN/killer-NIC driver blocking promiscuous mode VBoxManage list bridgedifs for exact names; temporarily --nic1 nat to prove the rest of the stack, then rebind
Internet dies whenever the laptop switches Wi-Fi ↔ Ethernet bridge bound to the now-inactive physical NIC VBoxManage modifyvm badcourt-ubuntu --bridgeadapter1 "<new name>" + sudo netplan apply; or add a third VM NIC for the other medium

PowerShell

Ubuntu 
sudo cp /home/admin/deploy/bad-court-management-qa.war /opt/tomcat/webapps/
sudo chown tomcat:tomcat /opt/tomcat/webapps/bad-court-management-qa.war
sudo systemctl restart tomcat          # Tomcat re-expands the WAR on start
